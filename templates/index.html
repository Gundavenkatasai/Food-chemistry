📑 Coursework Project Summary & Methodology

Report Sections 3, 5, 9, 10

1. Project Overview & Objectives

Food-chemistry datasets often contain structured laboratory measurements that can be analyzed to investigate patterns associated with different product categories. This project uses 13 chemical constituents measured in wines grown in the same region of Italy to classify each sample into one of three grape cultivars. The work combines a NoSQL database workflow (MongoDB Atlas / PyMongo) with a conventional machine-learning pipeline (Scikit-learn).

2. End-to-End Methodology Sequence

  1. Dataset Loading & Validation: 178 UCI wine records loaded, verified 0 missing values, 0 duplicates.
  2. Exploratory Data Analysis: Class count plots, histograms, correlation heatmap, standardized boxplots.
  3. MongoDB Atlas Integration: Cloud-hosted cluster connection via PyMongo, seeding WineAnalysisDB.wine_samples, querying and retrieving records.
  4. Preprocessing & Holdout Split: Stratified 75/25 split (133 train, 45 test) preserving class balance. StandardScaler fitted for Logistic Regression.
  5. Classifier Training & Comparison: Decision Tree (max_depth=5), Logistic Regression (scaled, max_iter=1000), Random Forest (200 trees, balanced).
  6. Validation & Artifact Export: Stratified 5-fold cross-validation on Random Forest; serialization of fitted model, scaler, metrics, and CSV reports.

3. Key Limitations & Academic Integrity

  • Dataset Size: 178 instances is a compact dataset; performance metrics can vary with splits.
  • Holdout Sensitivity: Holdout test set holds 45 records; a single changed prediction shifts accuracy by ~2.2%.
  • Perfect Holdout Scores: 100% holdout accuracy for Random Forest and Logistic Regression reflects the well-separated nature of the UCI Wine dataset rather than infinite generalization.
  • Correlation vs Causation: Feature importances reflect statistical patterns and do not prove biochemical causation.

4. References

  • Aeberhard, S. & Forina, M. (1992). Wine [Dataset]. UCI Machine Learning Repository.
  • MongoDB Documentation & PyMongo Driver Manual.
  • Scikit-learn, Pandas, Matplotlib, and Seaborn Documentation.
